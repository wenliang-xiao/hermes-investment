# ADR-0007：回测可信度口径

- 状态：Accepted
- 日期：2026-11-03
- 关联：ADR-0005
- 代码：`scripts/run_backtest.py`、`engine/evaluator_fixed.py`、`engine/backtest.py`、`engine/factor_engine.py`、`engine/backtest_storage.py`

## 背景

审计发现对外引用的回测数字（如 v17 年化 23.1% / 回撤 -14.5%）**不可复现**，
原因有五个：

1. `scripts/run_backtest.py` 解析了 `--from/--to` 并打印，但**从未传给**
   `evaluate_strategy`；实际永远跑固定数据窗口。
2. 默认 `use_point_in_time=False`，用写死的 `FIXED_SCORE_MAP` 评分 —— 评分含前视。
3. 策略四 `run_macro_driven_allweather` **完全没扣交易成本**，而策略一/三扣了。
4. IC 回算把"下期收益"算出的 IC 记在**评分日**上，历史回放会提前看到未来 IC。
5. 结果文件缺少口径元数据（实际数据窗口、评分模式、幸存者偏差），无法判断数字出自哪套口径。

## 决策

1. **日期区间真正生效**：`evaluate_strategy` 新增 `start_date/end_date`，按真实交易日
   同步裁剪 close/date 序列；`run_backtest.py` 透传 `--from/--to`。
2. **默认时点评分**：`run_backtest.py` 默认 `use_point_in_time=True`；保留
   `--fixed-score` 仅用于复现旧的前视结果。
3. **补成本**：`run_macro_driven_allweather` 对个股调仓、止损、趋势止盈按
   `|目标权重-旧权重| × _trade_cost(...)` 扣减当日净值。ETF 目标权重不建模再平衡成本。
4. **修 IC 时间戳**：`compute_ic_from_realized(score_date, returns, realized_date=None)`
   以 `realized_date`（收益实现日，默认今天）入库，`score_date` 作为字段保留。
5. **元数据落盘**：
   - 回测结果 `meta` 增加 `actual_date_range`、`data_window_days`、`scoring_mode`、
     `use_point_in_time`、`include_delisted`、`survivorship_bias`、`engine`；
   - `save_result` 旁挂 `data/backtest/bt_<run_id>.meta.json`，报告引用数字时直接对照口径；
   - `cost_model.model` 注明成本模型来源。
6. **冻结历史数字**：`docs/STRATEGY.md §7` 顶部加冻结声明，旧数字仅留档，不得对外引用。
7. **死代码标记**：`run_strategy4` 标注 DEPRECATED（无入口调用），实际策略四走
   `run_macro_driven_allweather`。
8. 修复 `analysis/score_history.py` 桥不导出下划线函数导致的 ImportError
   （改为从 `engine.score_history` 直接导入私有 helper）。

## 后果

**收益**
- 同一命令 + 同一区间 → 可复现结果；报告数字自带口径。
- 成本计入后策略四收益会下降，这是更真实的口径。
- IC 分析不再有前视。

**代价/风险**
- 时点评分慢约 10x，回测耗时显著增加。
- 策略四回测结果与历史数字不可比（现在扣成本）。
- `--from` 早于默认窗口时会拉取更长历史，首次运行较慢（新缓存文件按天数命名）。

**范围**
- 影响：回测 CLI、评估器、策略四回测、IC 入库、结果存储、文档。
- 不包含：数据源本身的历史复权/退市股补全质量；ETF 再平衡成本。

## 替代方案

| 方案 | 为什么没选 |
|------|-----------|
| 仅注明"旧数字不可复现"不改代码 | 之后还会继续产出不可信数字 |
| 保持 `--from/--to` 只打印 | 用户误以为区间生效，误导性更强 |
| 成本只加在策略一/三 | 策略四是主推策略，遗漏它等于美化主策略 |
| IC 继续按评分日入库 | 前视会污染因子权重自适应 |

## 验证方式

离线：
```bash
python -m py_compile engine/backtest.py engine/evaluator_fixed.py engine/factor_engine.py scripts/run_backtest.py
# 区间裁剪
python -c "from engine.evaluator_fixed import _slice_data_window; ..."
# 成本：同一合成数据，_trade_cost=0 的最终净值必须高于正常成本
```
已执行：区间裁剪、成本扣减、IC 时间戳、meta 旁挂文件均通过离线断言。

生产（需部署机联网）：
```bash
python scripts/run_backtest.py faceji --from 2020-01-01 --to 2024-12-31
cat data/backtest/bt_*.meta.json   # 核对 actual_date_range/scoring_mode/cost_model
```

## 回滚方式

回滚上述 5 个代码文件 + `docs/STRATEGY.md` 冻结声明到基线 `eb2128f`。
已有的回测结果文件不受影响；删掉 `*.meta.json` 即可回到旧目录结构。
