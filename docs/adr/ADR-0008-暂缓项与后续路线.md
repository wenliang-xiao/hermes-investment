# ADR-0008：暂缓项与后续路线

- 状态：Accepted
- 日期：2026-11-03
- 关联：ADR-0005、ADR-0006
- 说明：本 ADR 记录**审计发现但本次未改**的项。不是"没问题"，而是"有意暂缓"，
  留档原因与再次启动的条件，避免下次审计重复发现、重复讨论。

## 背景

2026-11 审计列出 4 项策略偏差，改动面涉及回测重跑与策略语义变更，本次
"止血 + 对齐 + fail-closed + 回测可信度"四步优先，故暂缓。

## 暂缓项

### 1. 换仓阈值（文档写 20%，代码未实现）

- 现状：文档 `docs/STRATEGY.md §5.3` 提到"换仓需新标的评分高出 20%"，
  代码里只有排名替换，没有阈值约束。
- 暂缓原因：会显著降低换手，需要先有可信回测（ADR-0007）才能评估收益影响。
- 启动条件：ADR-0007 新口径回测跑通，且换手率/成本数据齐备。
- 预估影响：交易次数下降、单次持有期变长、可能错过突发机会。

### 2. 衰退期禁开仓

- 现状：宏观引擎有 `strategy_switch=off/limited/on` 与双门，但没有"衰退期禁止新开仓"的硬规则。
- 暂缓原因：与 fail-closed 叠加可能长期空仓；需要明确衰退期定义与解除条件。
- 启动条件：宏观象限历史胜率统计完成。
- 预估影响：熊市回撤更小，牛市初期可能踏空。

### 3. CPI 五档仓位乘数

- 现状：`backtest._relaxed_gate_val` 是五档（1.0/0.85/0.8/0.5/0.4），
  但实盘宏观引擎用 `on/limited/off → 0.7/0.4/0.05`，两套口径不一致。
- 暂缓原因：需要先确定实盘用哪套，并同步回测，否则又是一个"两套账"。
- 启动条件：宏观引擎与回测的映射表统一评审通过。
- 预估影响：仓位随 CPI 更平滑或更陡，取决于最终方案。

### 4. TradingAgents "真辩论"

- 现状：`tradingagents.py` 是 bull/bear/neutral 加权公式，不是真正多 Agent 辩论；
  文档用"辩论制"描述，存在名实不符。
- 暂缓原因：真实的 LLM 多 Agent 辩论成本高、不可复现，不适合每日 cron。
- 启动条件：有独立的离线实验流程，且结果能落盘复现。
- 预估影响：信号更慢、更贵；短期不建议上线。

## 决策

1. 以上 4 项**本次不改**，在 `docs/design/risk-and-ledger-refactor.md` 中作为"Out of scope"记录。
2. 任何一项启动前，先写新的 ADR 或在本文追加"启动记录"（日期/理由/方案）。
3. 不得在没有新 ADR 的情况下顺手改这些行为。

## 后果

**收益**
- 暂缓原因可追溯，避免"审计报告年年提、年年不改"。
- 防止在回测不可信时做大改动。

**代价/风险**
- 策略与文档仍有已知偏差（换仓阈值、CPI 档位、辩论制表述）。
- 需要在后续迭代中持续跟踪。

## 替代方案

| 方案 | 为什么没选 |
|------|-----------|
| 本次一起改完 | 改动面过大，无法验证；回测口径还没修 |
| 完全不记录 | 下次审计重新发现，重复讨论 |

## 验证方式

- `docs/design/risk-and-ledger-refactor.md` 的 Out of scope 章节与本文件一致。
- 代码中暂无这些行为的实现（可用 grep 确认无"换仓 20%"/"衰退禁开仓"逻辑）。

## 回滚方式

本 ADR 仅记录，无运行时改动，无需回滚。删除本文件即可撤销留档。
