## 二、如何读日报（5 分钟）

飞书自动收到「面基·LDS 三源融合·开盘前/收盘后决策简报」。

### Step 1：看「一、今日决策面板」（30 秒）

**第一眼看双门状态**：

```
🔒 双门关闭 → 今天不开新仓，只检查止损
✅ 双门开启 → 可以正常操作
```

看「双门转绿条件」了解还差多少。

**看宏观象限 + 策略四当期配比**：

```
扩张期 → A股 25% | 股票ETF 20% | 债券 10% | 黄金 15% | 商品 15%
衰退期 → A股 20% | 股票ETF 10% | 债券 30% | 黄金 30% | 商品 10%
```

### Step 2：看「二、持仓风控」（1 分钟）

- `🚨触发止损!` 标记 → **今日必须处理**，收盘前执行
- 检查 trailing stop 价格距现价还有多远
- 持仓 < 10 天的票：注意 −8% 硬止损线

### Step 3：看「三、观察池今日信号」（1 分钟）

**「⭐ 今日有信号」部分**：
- RSI 超卖 (< 25) → 可能是买点，配合双门状态
- MA60 大幅偏离 < −15% → 超跌关注
- 大涨 ≥ 5% → 下方情报会有驱动分析

看 **MA20 / MA60 买点参考价**，右侧入场时对比现价。

### Step 4：看「五、今日情报」（1 分钟）

- 异动股驱动因素 AI 分析（≥ 5% 异动自动触发）
- 判断：噪音？还是真实基本面/政策变化？
- 如果是利好驱动的大涨 → 配合双门状态决定追入

### Step 5：看「六、调仓建议」（30 秒）

- 当期象限配比提示
- 「交易纪律」部分快速确认操作是否合规

## 三、如何读周报

每周日 18:00 飞书收到「面基·LDS 周报」。

### 必做三件事

**① 九、15 链深度研究（10 分钟）**

每条链的关注点：

| 信号 | 含义 | 动作 |
|------|------|------|
| Perez **展开期** | 格局清晰，规模化放量 | 可重仓 |
| Perez **导入期** | 最大不确定 + 最大涨幅窗口 | 半仓（凯利半注） |
| Perez **成熟期** | 利润竞争，增速放缓 | 轻仓，优先利润池顶端 |
| Perez **衰退期** | 行业萎缩 | 不参与 |

关注：链的「核心标的」 + 「催化剂」 + 「失效条件」。

**② 十、选股漏斗（5 分钟）**

```
L1 宏观门控状态（当前允不允许开A股仓）
L2 本周链内候选（从九来的具体票，含买点/触发条件/失效条件）
L3 多因子动量扫描（补充发现）
```

**十四、链内候选** 是最终可操作的清单，每只票标注：
- 评分（≥ 7.0 优先关注）
- 买点价格区间
- 触发条件（满足才操作）
- 失效条件（出现则放弃）

**③ 八、调仓建议（3 分钟）**

- 策略四当期配比 vs 实际持仓：哪类资产偏离了？
- 是否需要月度再平衡？
- 双门状态决定是否执行

## 四、找票流程：三层漏斗

```
周报九（15链深度）
  → 链景气判断，确认参与方向
       ↓
周报十四（链内候选）
  → 具体票 + 买点 + 触发/失效条件
       ↓
日报三（观察池信号）
  → 技术面右侧确认（价格>MA60 + MA20>MA60）
       ↓
    ✅ 满足 → 建仓
```

### L1：链景气判断（周报九）

问：**这条链现在值不值得参与？**

看 Perez 阶段、利润池、催化剂是否在下周会兑现。

### L2：链内候选筛选（周报十四）

触发条件未满足 → 加入观察池，**不操作**  
触发条件满足 + 双门开启 → 进入建仓流程

### L3：技术面右侧确认（日报三）

```
右侧入场三重确认（缺一不可）：
  ✅ 价格 > MA60
  ✅ MA20 > MA60（均线多头排列）
  ✅ 宏观象限非衰退期/过热期
```

## 五、建仓 SOP

### 5.1 建仓前检查（6 项，缺一不可）

```
☐ 双门状态 = 开启（或至少黄灯 + 绿灯组合）
☐ 宏观象限 ≠ 衰退期 / 过热期（或有特殊脱钩逻辑）
☐ 价格 > MA60 且 MA20 > MA60
☐ 该票通过质量门控（ROE 非持续负 + 营收非崩塌）
☐ 当前 A 股仓位 < 策略四当期 A 股配比上限
☐ 单票建仓后不超过总资产 2%
```

### 5.2 建仓方式：分两批

```
第一批（50% 目标仓位）：触发条件满足时立即建
第二批（50% 目标仓位）：
  方案 A：建仓后价格继续上涨突破新高 → 加满
  方案 B：建仓后小幅回调到 MA20 附近 → 加满
  方案 C：持仓超 10 天无明显进展 → 不加，等换仓日评估
```

### 5.3 仓位计算

```
凯利简化公式：
  单票最大仓位 = min(2%, 历史胜率 × 赔率 × 0.5 × 0.5)

实践规则：
  第一批：总资产 × 1%
  第二批：总资产 × 1%
  单票合计上限：总资产 × 2%

A 股总仓位上限（策略四当期）：
  扩张期：25% | 复苏期：30% | 过热期：15% | 衰退期：20%（但不开新仓）
```

## 六、持仓管理 SOP

### 6.1 每日 1 分钟检查

打开日报「二、持仓风控」：

```
有 🚨触发止损! → 今日收盘前执行止损，不犹豫
Trailing Stop 价格接近 → 提前挂好止损单
```

### 6.2 Trailing Stop 规则（v17）

| 持仓时间 | 触发条件 | 执行 |
|---------|---------|------|
| < 10 天 | 当前价跌破「成本 × 0.92」 | 全部止损 |
| ≥ 10 天，盈利 ≥ 30% | 从历史峰值回撤 > 12% | 全部卖出 |
| ≥ 10 天，盈利 10%−30% | 从历史峰值回撤 > 15% | 全部卖出 |
| ≥ 10 天，盈利 < 10% 或亏损 | 从历史峰值回撤 > 20% | 全部卖出 |

**关键原则**：止损价只能**上移**（锁定更多利润），**不能下移**（避免拿着亏损死扛）。

### 6.3 主动止损（基本面恶化）

以下情况不等 trailing stop，立即清仓：

```
☐ 该公司 ROE 连续 2 季度下降超过 30%
☐ 产业链出现颠覆性竞争（新技术替代本链逻辑）
☐ 该票被 ST 或出现退市风险
☐ 宏观象限切换到衰退期，且该票是纯周期股
```

## 七、调研优质票：Nick 四问

当某只票出现在周报十四候选或日报三信号时，启动调研。

### 第一问：为什么是现在？

- 什么催化剂让这条链现在值得参与？（政策/技术突破/竞争格局变化）
- Perez 阶段是展开期还是导入期？
- 催化剂是否还未被市场充分定价？

### 第二问：为什么是这个公司？

- 在利润池里是哪个环节？毛利率多少？（链内顶端优先）
- ROE 趋势：加速还是减速？（面基「肥美期」= ROE 加速度 > 0）
- 护城河：技术壁垒/成本优势/网络效应哪个更强？

### 第三问：为什么现在价格合理？

- PEG = PE / 净利润增速，最好 < 1.5
- 和链内同类公司估值比，有没有折价？
- 历史 PE 百分位（参考，不用来排名，但极端高估时谨慎）

### 第四问：什么情况下我是错的？

- 失效条件是什么？（周报十四候选票会写）
- 如果失效，最大亏损是多少？（对应止损价）
- 我愿意承受这个亏损吗？

### 调研结果评级

| 评级 | 标准 | 动作 |
|------|------|------|
| **A 级** | 四问全过，估值合理，右侧确认 | 建仓（双批建） |
| **B 级** | 逻辑清晰但估值偏贵，或等右侧确认 | 加入观察池，等触发 |
| **C 级** | 逻辑有疑问，或象限不支持 | 不操作 |

## 八、清仓 SOP

### 8.1 被动清仓（止损触发）

按第六章 trailing stop 规则执行，**不犹豫，不加仓摊低成本**。

### 8.2 主动清仓（换仓）

```
在下一个再平衡日（每 4 周一次）：
  新票动量分 > 当前最弱持仓分 × 120%
  → 卖出最弱持仓，买入新票
  
衰退期/过热期：不开新仓，存量持有到 trailing stop 触发
```

### 8.3 主动清仓（基本面变化）

见 6.3 节，基本面恶化时不等换仓日，立即清仓。

### 8.4 策略性清仓（宏观切换）

```
象限切换到「衰退期」：
  → 不开新 A 股仓
  → A 股存量：触发 trailing stop 才卖
  → 同步增加债券 ETF（511260）和黄金 ETF（518880）配比

双门完全关闭（红灯 + 红灯）：
  → 检查所有持仓 trailing stop
  → 不开新仓，等双门转绿
```

## 九、月度再平衡 SOP

**频率**：每月最后一个交易日收盘后

### 步骤

```
1. 查当前实际资产配比
2. 对照策略四当期配比（日报/周报「调仓建议」板块）
3. 偏离 > 5% 的类别：
   ├── 超配 → 部分卖出，资金买入低配资产
   └── 低配 → 用新增资金买入，或从超配调仓
4. ETF 层：从各类别池选动量评分最高的 ETF
5. 更新 shadow_account 记录
```

**不需要再平衡的情况**：
- 全部资产偏离均在 5% 以内
- 双门关闭（等转绿再平衡）

## 附：常见问题

**Q：两条链的候选票都很好，怎么选？**  
A：优先 Perez 展开期的链，其次看利润池排名更高的环节。同等条件下选 60−120 日动量更强的票。

**Q：双门关闭了很久，持仓快到 trailing stop 了，要不要提前卖？**  
A：按规则来。触发了 trailing stop 就卖，没触发就持有。双门关闭 ≠ 清仓，只是不开新仓。

**Q：某只票大涨 20%，要不要止盈？**  
A：不要主动止盈。Trailing stop 会自动保护：盈利 30%+ 后从峰值跌 12% 才卖。这样能让赢家跑得更远。

**Q：RSI 超卖了，可以买吗？**  
A：RSI 超卖只是信号之一，还需要：①双门开启 ②在链内候选里 ③右侧确认（价格 > MA60）。三个都满足才操作。

**Q：资金量很小，2% 上限意味着每票仓位很小？**  
A：2% 是上限，保证组合够分散。可以根据实际资金量适当调整，但单票集中度不要超过 10%。
