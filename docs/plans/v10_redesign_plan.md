## 🧱 工作包 1：三策略融合运行引擎

### 目标
每天跑三个策略，输出信号对比表——哪个策略想买什么、想卖什么、为什么。

### 改动点

| 文件 | 改动 | 
|------|------|
| 新建 `scripts/run_trading.py` | 三策略逐日执行器，输出 `data/trading_signals.json` |
| 新建 `analysis/trading_engine.py` | 策略调度器：顺序执行 faceji → SQ → TA |
| 修改 `scripts/run_daily.py` | 日报中引入 `trading_signals.json` 作为节2/节3/节6的内容来源 |
| 修改 `scripts/portfolio_server.py` | `/api/signals` 端点暴露信号 |

### 信号格式

```json
{
  "date": "2026-06-24",
  "signals": [
    {
      "id": "SIG-20260624-001",
      "strategy": "faceji",
      "action": "BUY",
      "symbol": "603259",
      "name": "药明康德",
      "price": 92.21,
      "size_pct": 3.0,
      "reason": "评分6.2+MA趋势向上",
      "priority": "HIGH"
    },
    {
      "id": "SIG-20260624-002", 
      "strategy": "silverquant",
      "action": "SELL",
      "symbol": "300502",
      "name": "新易盛",
      "price": 579.97,
      "reason": "MASeller(MA死叉)",
      "pnl_pct": -2.3
    }
  ]
}
```

### 执行流程
1. `run_daily.py` 完成扫描后 → 调用 `trading_engine.run_all()`
2. 三策略各自输出买卖信号 → 去重/合并/优先级排序
3. 写入 `trading_signals.json` → 日报引用
4. 信号按优先级：冲突信号取最高评分策略的建议

### 你的工作流

```
日报生成 → 看到信号表 → 你打开富途/牛牛执行
       ↓                              ↓
    agent 等待反馈              你告诉 agent"买入了"
       ↓                              ↓
    agent 记录到 shadow_account      ← 反馈完成
```

### 交易纪律（硬编码到代码中）

- 🚫 每周任一策略最多交易 1 次（开仓 or 清仓）
- 🚫 所有策略合计每周最多 3 次交易
- 🔒 黑天鹅例外（单日跌 >6% 或宏观危机事件）
- 📊 交易日历自动识别（A股交易日历，非交易日不生成信号）

## 🧱 工作包 3：因子升级（SilverQuant 风控 + TA Kelly）

### 将 SilverQuant 组件化卖点嵌入面基策略

面基当前清仓：
```
评分<4 → 卖出
评分<5 + MA死叉 → 卖出
```

升级后（融合 SilverQuant）：
```
评分<4.5 → 卖出                    # ScoreDropSeller (from SQ)
浮动亏损 ≥ -8% → 硬止损卖出        # HardSeller (from SQ)
峰值回落 ≥ -12% → 止盈卖出         # FallSeller (from SQ)
MA死叉 + 亏损<5% → 卖出            # MASeller (from SQ)
```

### 将 TA Kelly 仓位管理嵌入面基策略

面基当前仓位：固定 ¥30K/槽位

升级后：
```
win_prob = min(评分 / 10.0, 0.8)
kelly_raw = (win_prob * 2.0 - (1 - win_prob)) / 2.0  # 赔率设为 2:1
kelly_final = kelly_raw * 0.5                         # 半凯利
position = cash * min(kelly_final, 0.08)               # 上限 8%
```

### 评分动态化

当前：评分60天不变  
目标：每日扫描触发评分更新（已在 `run_daily.py` 中实现，但评分不显式传递到回测）

## 🧱 工作包 5：中观产业链分析

### 核心思想

>"买在利润最厚的环节，不买整条链"——面基播客核心方法论

### 改动

| 文件 | 改动 |
|------|------|
| 新建 `analysis/chain_scanner.py` | 按12条产业链扫描利润池位置 |
| 修改 `analysis/factor_scanner.py` | 给评分增加 "chain" 标注 |
| 修改 `scripts/run_daily.py` | 日报中新设 "产业链发现" 子节 |

### 12条产业链（来自面基知识体系）

1. 英伟达算力链 → 利润池：光模块(30-55%)、HBM(50%+)
2. 台积电先进制程链 → 利润池：半导体设备(40-55%)、CoWoS(45%+)
3. 机器人核心零部件 → 利润池：减速器(40%)、伺服电机(30%)
4. 半导体链 → 利润池：设计IP(80%+)、设备
5. AI电力 → 利润池：核电PPA、燃气轮机
6. 新能源链 → 利润池：储能逆变器
7. 军工链 → 利润池：连接器、材料
8. 医药创新链 → 利润池：CXO、创新药
9. 消费防守链 → 利润池：高端白酒
10. 金融链 → 利润池：零售银行
11. 电网设备链 → 利润池：超高压变压器
12. 大宗商品链 → 利润池：铜、黄金

### 评分增强
每个标的除了六因子分数外，增加：
- `chain_position`：上游/中游/下游
- `profit_pool_score`：利润池厚度分（0-10）
- `bottleneck_score`：瓶颈度分（越瓶颈分越高）
