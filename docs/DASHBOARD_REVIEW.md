## 二、各面板逐项体验

### 2.1 📊 模拟盘（首页）

**数据加载**：页面加载即显示，自动 2 分钟刷新 ✅

**展示内容**：
- 三策略卡片：面基/SilverQuant/TradingAgents，各显收益率+总资产+现金+持仓数+胜率
- 组合净值曲线：Chart.js 折线图，三策略叠加对比
- 策略信号日志：方向/标的/策略/备注表格 + 管道统计（原始信号→冲突解决→周频过滤→执行）
- 当前持仓：每只持仓卡片含收益率/买入现价/持有天数/回撤/止损线/评分变化 + 7因子雷达图
- 交易历史：日期/标的/方向/价格/数量/盈亏/持有天数/理由表格，买入绿色底/卖出红色底

**体验评价**：
- ✅ 三策略收益一目了然，卡片颜色区分清晰
- ✅ 持仓雷达图直观展示因子强弱
- ✅ 信号管道透明（原始→过滤→执行数量可视化）
- ⚠️ 持仓卡片的"理由"字段大多截断显示，hover tooltip 不够
- ⚠️ 净值曲线无基准对比（如沪深300）
- ⚠️ 无日期范围选择器，只能看全部历史
- 💡 建议：持仓卡片增加"加仓/减仓"建议按钮

## 三、技术发现

### 3.1 网络请求分析

| API | 响应 | 数据量 |
|-----|------|--------|
| `/api/v2/portfolio/detail` | 200 | 三策略持仓+信号+交易历史 |
| `/api/v2/portfolio/netvalue` | 200 | 净值曲线数据 |
| `/api/v2/pool/by_market` | 200 | 四市场三层票池 |
| `/api/v2/factor_explain` | 200 | 7因子定义+权重 |
| `/api/v2/dragon_tiger` | 200 | 91条龙虎榜+席位明细 |
| `/api/v2/etf/scan` | 200 | ETF 扫描（无数据，返回空） |
| `/api/v2/etf/portfolio` | 200 | ETF 组合（无数据） |
| `/api/v2/news?limit=200` | 200 | 189条新闻+情感标记 |
| `/api/v2/news/sentiment` | 200 | 情感汇总 |

### 3.2 前端架构

- 框架：原生 JS，无 React/Vue
- CSS：Tailwind CDN
- 图表：Chart.js 4.4.7 CDN
- 路由：单页应用（hash SPA），`switchTab()` 切换面板
- 刷新机制：`setInterval(loadDashboardV2, 120000)` + 各面板独立 `setInterval`
