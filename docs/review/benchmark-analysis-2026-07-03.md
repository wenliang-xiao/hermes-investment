### 2.3 核心偏离

**最严重的偏离是评分引擎的描述**。STRATEGY.md 描述的是 factor_engine v4.0 的截面分位法，但 `run_daily.py` 实际运行的是 factor_scanner v3.1 的固定区间映射。两者数学性质完全不同——截面分位是相对排名（自适应市场），固定区间是绝对阈值（市场涨跌时系统性偏移）。

## 三、能否对标专业量化公司？

### 3.1 分层对标

```
层级4: 机构级 (BlackRock/AQR/Two Sigma)
  - 自有数据中心 + 专有数据源 + 硬件加速
  - Hermes 差距: 10年以上

层级3: 专业量化平台 (QuantConnect/VeighNa)  
  - 事件驱动引擎 + 插件化架构 + PIT数据 + 组合优化 + 实盘直连
  - Hermes 差距: 2-3年

层级2: 研究级平台 (Qlib/Zipline)
  - 因子研究工具 + 回测引擎 + ML集成 + 学术级验证
  - Hermes 差距: 6-12个月

层级1: 个人量化工具
  - 评分+排序+等权+手动执行
  - Hermes 当前定位 ✓
```

**结论：Hermes 处于层级 1（个人量化工具），有潜力达到层级 2（研究级平台）。要到层级 3（专业平台）需要架构重写。**

### 3.2 核心竞争力（Hermes 独有的）

| 能力 | 说明 |
|------|------|
| **LDS 双门风控** | 货币信用四象限 + 国运线趋势温度，9 种组合状态→仓位建议。这是独特的宏观量化融合 |
| **三策略并行** | 不同仓位管理哲学（Kelly/固定槽/辩论制）同时运行，用户可以看到同一信号的不同处理方式 |
| **产业链深度** | 15 链中观分析（含利润池/翻倍逻辑/催化剂/假设验证），超越了纯因子的量化 |
| **面基概念引擎** | 26 个投资概念（DCF/Kelly/Bayesian更新/四重确认等），封装为可调用分析函数 |

这些是 Hermes 区别于其他平台的独特价值，也是开源后最可能吸引用户的差异化能力。

### 3.3 致命短板（阻止对标）

| 短板 | 影响 |
|------|------|
| **无事件驱动架构** | 无法扩展到多策略同时运行、无法做 tick 级回测 |
| **无风险模型** | 组合风险不可见，专业量化团队不可能用 |
| **对比数据造假** | 用户看到的回测结果是随机生成的——信任崩塌 |
| **无实盘接口** | 无法从信号直接下单，永远停留在"纸上谈兵" |
| **无测试** | 94 文件 0 测试，无法证明因子引擎的正确性 |
| **无许可证** | 没有 LICENSE 文件，开源社区无法合法使用 |

**就绪度评分：4/13 = 31%**

### 4.2 开源上线时间线预估

| 阶段 | 时间 | 工作 |
|------|------|------|
| **Phase 0: 止血（1 周）** | 立即 | 移除硬编码凭据、添加 LICENSE、修复对比假数据、加 .env.example |
| **Phase 1: 基建（2 周）** | 之后 | pyproject.toml、ruff 配置、CI/CD、核心路径单元测试 |
| **Phase 2: 可信（3 周）** | 之后 | 真实回测对比、连续净值记录、数据快照机制 |
| **Phase 3: 上线（2 周）** | 之后 | README 丰富、CONTRIBUTING.md、示例策略、文档完善 |

**最快开源时间**: 2 个月（Phase 0-3 完成）

### 4.3 开源前的关键决策

**决策 1：要不要保留飞书依赖？**
- 当前日报生成依赖飞书 API。如果开源，用户可能没有飞书
- 建议：日报输出抽象化（飞书/Markdown/Notion 可切换）

**决策 2：要不要移除硬编码的产业链数据？**
- 15 链分析是核心特色，但配置数据在源码中
- 建议：移到 YAML 文件，保留作为示例数据

**决策 3：要不要公开 Dashboard？**
- Dashboard 目前是 FastAPI 内嵌 HTML，无认证
- 建议：加 Basic Auth 或 Token 认证，或提供 Docker 一键部署

## 五、最终结论

### 5.1 分层定位

```
你能做的（今天）:
  个人量化辅助 → 因子筛选 + 组合监控 + 手动跟单 ✓

你差一步的（1-2 个月）:
  研究级工具 → 真实回测 + 因子评价 + 组合优化 + 数据快照 ⚠️

你差三年以上的（需要架构重写）:
  专业平台 → 事件驱动 + 多策略 + 实盘直连 + 并发用户 ❌
```

### 5.2 开源价值判断

**Hermes 有明确的开源差异化价值**——LDS 双门风控、产业链深度、面基概念引擎、三策略并行——这些是其他开源量化平台没有的。但需要在发布前完成"止血"工作（凭据、假数据、LICENSE、测试）。

**如果现在开源**：会被人发现假数据问题而失去信任。
**如果 2 个月后开源**：可以成为一个有特色的个人量化工具，填补"产业链量化"和"面基投资理念"的细分空白。

### 5.3 一句话总结

**Hermes 不是 QuantConnect 的竞品，也不应该是。它是一个"带产业链深度的个人量化辅助系统"——这个定位是有价值的。走开源路线需要先做好三件事：修假数据、加测试、加 LICENSE。**
