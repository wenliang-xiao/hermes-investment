# 面基投资系统 · 术语表

> 本表收录系统中出现的关键术语，按拼音排序。

| 术语 | 含义 | 来源/备注 |
|------|------|-----------|
| 不为清单 | 段永平投资理念：一组硬否决规则，如"不买不懂的""不买有硬伤的" | 段永平，用于人工审核层 |
| 辩论制 | TradingAgents 策略风格：bull/bear/neutral 三信号加权裁决（注意：是加权公式，非真正多 Agent 辩论，见 ADR-0008） | 模拟多 Agent 辩论 |
| 产业链 | 按上下游关系将标的归入特定链条（如"AI算力-GPU"、"半导体-存储"） | 面基播客方法论 |
| 策略四账本 | `data/shadow_strategy4.json`，run_daily 的策略四专用账本，`owner=strategy4`，由 `output.shadow_account` 独占写 | ADR-0004 |
| 发现-盯住-深度 | 三层票池机制：发现层(>0.50) → 盯住层(>0.55≥1周) → 深度层(>0.6≥2周) | 系统独创 |
| 国运线 | A股长期趋势线，用于判断市场整体位置 | 面基播客概念 |
| 回撤止盈（四档 Trailing） | 持仓 <10 天只走 -8% 硬止损；满 10 天后浮盈 ≥30% 回撤 -12%(T3)、10~30% 回撤 -15%(T2)、其余/亏损回撤 -20%(T1) | ADR-0005，实现于 `strategies.base.trailing_stop_threshold` |
| 面基 | 面基播客社区的投资理念体系，强调基本面 + 产业链思维 | 播客: 面基 |
| 时点评分（Point-in-Time） | 回测按每个历史时点当时可见的数据重算评分，避免用未来信息；`evaluator_fixed` 每 5 交易日 rescore | ADR-0007 |
| 收益实现日 | IC 回算中下期收益真正可知的日期；IC 快照以此日入库，不得用评分日 | ADR-0007 |
| 幸存者偏差 | 只用当前仍在册标的回测，忽略已退市/被剔除标的，导致收益高估；`--include-delisted` 可缓解 | ADR-0007 |
| 三源融合 | 同时融合 面基(基本面) + LDS(产业链) + 技术分析 三套体系 | 系统核心理念 |
| 双门 | 两层滤波机制：OR严格版 + MA60-5% 趋势过滤 | 回测 v9 验证过的最优组合 |
| 四层风控 | 旧称：HardSeller(-8%) → FallSeller(-12%) → ScoreDrop(<4.5) → MASeller(死叉)。现已被"四档回撤止盈 + 硬止损 + 评分/均线卖出"取代 | ADR-0005 |
| 五层漏斗 | 宏观气候 → 资产配置 → 多因子引擎 → 找票执行 → 风控监控 → 交易纪律 | 六层审计框架 |
| 趋势温度 | 基于 MA20/MA60 乖离率的技术面热度指标 | 系统计算 |
| SilverQuant | 银量策略：规则驱动、组件化风控（HardSeller/FallSeller/MASeller），买入按固定 ¥30,000 槽位 | 模拟盘三策略之一，ADR-0005 |
| TradingAgents | 交易员策略：辩论制多信号裁决 + Kelly 仓位管理 | 模拟盘三策略之一 |
| 主账 | `data/shadow_account.json`，三策略聚合模拟盘，`owner=run_trading`，由 run_trading / trading.bridge 独占写 | ADR-0004 |
| 账本收权 | 让每个账本文件只有一个写者，避免两套逻辑互相覆盖；本系统拆为"主账 + 策略四账" | ADR-0004 |
| fail-open | 拿不到证据时按"没问题"继续（如影子缺失仍允许买入）。本系统已全面废弃 | ADR-0006 |
| fail-closed | 拿不到证据时按"不安全"处理（禁止开仓）。本系统风控门统一采用 | ADR-0006 |
| buy_block_reason | 上游风控门给出的"今日禁止 BUY"原因；非空时只禁买入，卖出/止损照常 | ADR-0006 |
| risk_gates | `trading_signals.json` 中记录当日全部门控状态（事件/宏观/上游原因）的字段 | ADR-0006 |
| 冻结声明 | 对不可复现的历史对外数字（如回测 v17）标注"仅留档、不得引用" | ADR-0007 |
| 六因子 | 质量/价值/成长/动量/低波/情绪 —— 不含风险因子的评分体系 | 因子引擎 |
| 七因子 | 质量/价值/成长/动量/低波/情绪/风险 —— 含风险因子 | 因子引擎完整版 |
| 19子因子 | 因子引擎最底层：用于构建 7 风格因子的原始指标 | 详见 factor_engine.py |
